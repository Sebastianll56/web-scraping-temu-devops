Descripción del proyecto

Este proyecto aplica técnicas de extracción y procesamiento de información mediante Python y BeautifulSoup. Se utilizan herramientas de control de versiones, pruebas automatizadas e integración continua con GitHub Actions.

Tecnologías utilizadas

  • Python para el procesamiento de información.
  • BeautifulSoup para el análisis de documentos HTML.
  • Pytest para las pruebas automatizadas.
  • Git para el control de versiones.
  • GitHub para la gestión del repositorio.
  • GitHub Actions para la integración continua.
  • GitHub Pages para la publicación de la documentación.

Pruebas automatizadas

El proyecto dispone de pruebas con Pytest para verificar la extracción del título, precio, calificación y reseñas, así como el comportamiento ante documentos sin datos.

2 pruebas aprobadas en la ejecución verificada

Flujo de trabajo DevOps

El desarrollo utiliza ramas, commits y solicitudes de integración (Pull Requests). GitHub Actions ejecuta automáticamente las pruebas cuando se realizan cambios en la rama principal o se proponen modificaciones.

La publicación de esta documentación se realizará mediante GitHub Pages.
